# Ghat Watch

Ghat Watch is a water quality risk dashboard for Bhopal immersion ghats, designed for BMC officers to monitor and manage immersion sites against CPCB Class B standards.

## Features
- **Ghat Risk Dashboard**: Ranks immersion ghats based on water quality data.
- **AI-Powered Assistant**: Multilingual (English, Hindi, Hinglish) assistant to answer queries about ghat data.
- **Claim Guard**: Ensures AI responses respect health claim restrictions.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`
